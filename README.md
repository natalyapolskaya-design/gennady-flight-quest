# Открытка для Геннадия

Готовая автономная версия для GitHub Pages.

## Как получить ссылку

1. Создайте в аккаунте `natalyapolskaya-design` публичный репозиторий с точным названием `gennady-flight-quest`.
2. Загрузите в корень репозитория все файлы из этой папки, включая папку `assets`.
3. Откройте `Settings` → `Pages`.
4. В разделе `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main`, папку `/(root)` и нажмите `Save`.

После публикации открытка будет находиться по адресу:

`https://natalyapolskaya-design.github.io/gennady-flight-quest/`

## Важно

В папке находится настоящий электронный билет с действующим QR-кодом. При публикации в открытом репозитории скачать его сможет любой человек, которому известна ссылка. Не размещайте ссылку в открытом доступе.
